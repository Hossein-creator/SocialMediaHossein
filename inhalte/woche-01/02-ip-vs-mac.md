# Short 2: IP vs. MAC (Serie „شبکه به زبان ساده“, Teil 1)

**Länge:** 55–60 s (v2 mit Teaser und „geheimem Tipp“ für mehr Zuschauer bis zum Ende) · **Ziel:** Reichweite + Follow für die Serie

| Zeit | Gesprochen (Persisch) | Text-Einblendung |
|------|------------------------|------------------|
| 0–3 s | **هر دستگاهی که به شبکه وصل می‌شه، دو تا آدرس داره.** | IP یا MAC؟ 🤔 |
| 3–6 s | یکی MAC، یکی IP. ولی فرقشون چیه؟ آخر ویدیو هم یه نکتهٔ مخفی بهت می‌گم! | VS-Folie + Teaser |
| 3–14 s | اولی آدرس MAC ـه. این آدرس موقع ساخت روی کارت شبکهٔ دستگاهت ثبت شده و معمولاً عوض نمی‌شه. مثل شناسنامهٔ خودته. | MAC = شناسنامه 🪪 |
| 14–25 s | دومی آدرس IP ـه. این آدرس رو شبکه‌ای که بهش وصل می‌شی بهت می‌ده. مثل آدرس خونه‌ات: اگه جابه‌جا بشی، عوض می‌شه. | IP = آدرس خونه 🏠 |
| 25–35 s | مثلاً گوشیت توی خونه یه IP داره و توی کافه یه IP دیگه. ولی MAC ـش همونه. | 🏠 IP: 192.168.0.23 → ☕ IP: 10.0.0.57 |
| 35–45 s | داخل شبکهٔ خونه، دستگاه‌ها با MAC همدیگه رو پیدا می‌کنن. توی اینترنت، با IP. | شبکهٔ خونه ➜ MAC · اینترنت ➜ IP |
| 44–51 s | **و اون نکتهٔ مخفی: گوشی‌های جدید برای حریم خصوصی، توی هر وای‌فای یه MAC تصادفی نشون می‌دن!** | 🤯 🔒 |
| 51–58 s | **قسمت بعد: روتر و سوییچ چه فرقی دارن؟ فالو کن که از دستش ندی.** | قسمت ۲ ⏭️ |

**Hinweis für dich:** Der „geheime Tipp“ ist korrekt: Moderne Handys nutzen pro WLAN oft eine zufällige MAC-Adresse
(Privatsphäre). Deshalb steht im Skript „معمولاً“. Falls jemand in den Kommentaren fragt, ist das
eine perfekte Idee für ein eigenes Video.

**Optional:** Kurz am Handy unter *Einstellungen → WLAN → Details* die eigene IP und MAC zeigen
(Bildschirmaufnahme, 3 s). Danach die echten Adressen unkenntlich machen.
